# 03_논문원고 — 석사학위논문 최종 원고와 생성 스크립트

`02_성공실험_변동성방향성예측/` 의 실험 결과를 본문에 반영해 만든 최종 원고와,
그 반영에 실제로 사용한 python-docx 스크립트를 함께 보관한다.

## 적용 순서

파일명 접미사의 날짜 순서가 곧 적용 순서다.

```
_apply_v30_to_review.py
_fix_sec26.py
_fix_citations_20260921.py
_fix_citations_20260921_pass2.py
_apply_reexperiment_20260921.py
_replace_fig10_20260921.py
```

각 스크립트는 `--dry-run` 을 지원한다(`_apply_v30_to_review.py`, `_fix_sec26.py` 제외).
원고를 직접 덮어쓰므로 실행 전 사본을 떠 두는 것이 안전하다.

```bash
pip install -r ../requirements.txt     # python-docx, lxml
python _fix_citations_20260921.py --dry-run
python _fix_citations_20260921.py
```

## 경로에 관한 주의

스크립트는 원래 작업 폴더(`자기주도적/검토용 논문/`)에서 실행한 것을 **수정 없이** 그대로
보관한 것이다. 기록의 정확성을 위해 경로를 고치지 않았으므로, 이 폴더에서 재실행하려면
아래 두 가지를 확인해야 한다.

- 원고 경로: 대부분 `Path(__file__).parent / "(국문) 석사학위논문_임우현.docx"` 로 잡으므로
  이 폴더에서도 그대로 동작한다. 다만 `_apply_v30_to_review.py` 와 `_fix_sec26.py` 는
  원래 폴더의 **절대 경로**가 하드코딩돼 있어 수정이 필요하다.
- 그림 경로: `_replace_fig10_20260921.py` 는 `fig10_v15.png` 를
  `<스크립트 폴더>/../ETFpricepredictmodel/data/2014-2025/02_성공실험_변동성방향성예측/` 에서
  찾는다. 이 리포지토리에서의 실제 위치는 `../02_성공실험_변동성방향성예측/fig10_v15.png` 다.
