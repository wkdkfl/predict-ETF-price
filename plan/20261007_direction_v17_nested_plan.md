# 방향성 v17 사전 고정 프로토콜 — 중첩 워크포워드 모형·파라미터 탐색 (2026-10-07, 실행 전 작성)

목적: 모형·하이퍼파라미터·피처군을 폭넓게 탐색하되, 선택을 각 시점의 과거 자료 안에서만 수행하여
평가 AUC 가 탐색으로 부풀려지지 않게 한다. 결과를 본 뒤 후보 공간·선택 규칙을 바꾸지 않는다.

## 설계
- 표본·표적·외부 fold: v16 과 동일 (`dir5`, 8-fold 확장 워크포워드 2018-03~2025-12, pooled 학습, 엠바고 10행).
- 내부 선택: 각 외부 fold 의 학습 구간 뒤쪽 50% 를 3개 연속 구간으로 나누어 확장 워크포워드(엠바고 10행).
  시장별 내부 AUC 평균이 가장 높은 후보를 그 시장의 해당 fold 모형으로 선택 → 외부 fold 학습 전체로 재적합 → 외부 fold 예측.
- 부 규칙(사전 지정): 내부 상위 3개 후보 확률의 평균(앙상블).

## 후보 공간 (4 피처군 × 7 분류기 = 28)
피처군: AR(25) / FIN_clean(뉴스 파생 열 제외 금융지표) / AR+FIN_clean / Full(71)
분류기:
- 로지스틱 L2, C ∈ {0.001, 0.01, 0.1}
- LightGBM 얕은 설정 (depth 2, 300그루, lr 0.02, min_child_samples 200, subsample 0.8, colsample 0.8, λ 10)
- LightGBM 중간 설정 (depth 3, 500그루, lr 0.01, min_child_samples 100, subsample 0.7, colsample 0.7, λ 5)
- LightGBM v10 설정
- RandomForest (300그루, max_depth 4, min_samples_leaf 50, max_features sqrt)

## 판정
- 주: 규칙 1(단일 최고) 미국 OOS AUC 의 95% 블록 부트스트랩 CI 하한 > 0.5. 점추정 0.6 이상 여부도 함께 보고.
- 2 규칙 × 2 시장 = 4개 단측 p 에 Holm 보정.
- 각 fold 에서 선택된 후보를 모두 공개.
