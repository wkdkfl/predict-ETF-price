# 뉴스 활용 개선 실험 계획 (2026-09-20)

## 0. 목표와 원칙
- 목표: 신규 일별 뉴스에서 **예측에 기여할 가능성이 있는 정보**를 더 잘 뽑아내는 방법을 시험한다.
- **개선을 보장하지 않는다.** 시험 구간 성적을 보고 피처·모델을 고르면 과적합이므로 다음 원칙을 지킨다.
  1. 후보(피처군·모델)는 **실험 전에 이 문서에 고정**한다. 결과를 본 뒤 추가·삭제하지 않는다.
  2. 선택은 **시험 구간(≥2024-03-07)을 쓰지 않는 사전(pre-test) 워크포워드 검증**으로만 한다.
  3. 시험 구간은 선택된 후보와 기준선에 대해 **마지막에 한 번**만 평가한다. 전체 후보 결과도 함께 공개한다.
  4. 사전 검증에서 어떤 후보도 기준선을 이기지 못하면 "개선 없음"으로 보고한다(선택 = 기준선).
- 한계: 동일 시험 구간이 v3~v13 개발 내내 쓰였으므로 완전히 독립인 검증은 아니다. 2025-12-31 이후 자료가 없어 새 홀드아웃을 만들 수 없다.

## 1. 진단 — 왜 뉴스가 기여하지 못했을 가능성이 있는가 (기존 결과에서 확인된 것)
| 관찰 | 시사점 |
|---|---|
| 신규 뉴스는 하루 헤드라인이 5~8건이라 일별 평균 감성이 잡음이 큼(표준편차 0.08~0.10 → 0.29~0.31) | 감성 수준값을 그대로 쓰지 말고 **시간 평활화** |
| 감성 16개 + 임베딩 PCA 15개 = 31개를 학습 표본 약 2,100행(풀링 시 약 4,200)에 투입 | 차원 대비 표본이 작음 → **저차원·해석 가능한 피처** |
| 변동성은 뉴스의 **극성**보다 **양(뉴스 유입 강도)·주제**에 반응하는 것이 일반적 | 감성 대신 **뉴스 강도·주제 카운트** 피처 |
| 수집 시 헤드라인 선별로 하루 최대 10건으로 잘려 강도 정보가 손실됨 | 잘리기 전 **후보 전체**(`*_economic_news_candidates.csv`)에서 강도 산출 |
| 표본이 작고 잡음이 큰 문제에서 LightGBM(600그루)은 과적합 위험 | **선형(Ridge) 모형**을 대안으로 |

## 2. 후보 (고정)
**신규 피처** (모두 거래일 t 시점까지 발행된 뉴스만 사용, 비거래일 뉴스는 다음 거래일에 합산 — 기존 규칙과 동일)
- `INT` (9개, 뉴스 강도·주제): 후보 기사 수 `n_cand`, 점수≥3 기사 수 `n_hi`, 평균 관련도 점수, 주제 6종
  (정책 / 거시 / 무역·지정학 / 시장 / 기업 / 원자재·환율)별 기사 수. 수준 드리프트 제거를 위해 **과거 60거래일 평균 대비 비율**
  (분모는 shift(1)로 과거만 사용). 주제 분류는 `collect_economic_news.py` 의 HIGH_KW 정규식을 재사용.
- `SS` (6개, 평활 감성): `sent_score_mean`, `sent_neg_mean`, `sent_max_neg` 의 지수가중평균(span 5, 20) — 인과적(과거+당일).

**피처군**
| 이름 | 구성 | 역할 |
|---|---|---|
| F0 | AR_Only | 기준선 |
| F1 | AR + 기존 뉴스(감성 16 + 임베딩 PCA 15) | v10 뉴스 기준선 |
| F2 | AR + INT | 신규 |
| F3 | AR + INT + SS | 신규 |
| F4 | AR + INT + 감성 16(임베딩 제외) | 신규 |
| F5 | AR + SS | 신규 |

**모형** — 회귀: LightGBM(v10 고정 하이퍼파라미터, 차분 타깃, 풀링, 검증구간 MZ 보정) / Ridge(TimeSeriesSplit 으로 α 선택, 동일 타깃·보정).
분류: LightGBM(v10) / 로지스틱(L2, TimeSeriesSplit 으로 C 선택).
후보 총 수: 피처군 6 × 모형 2 × 타깃 2(변동성·방향성).

## 3. 선택 규칙 (시험 구간 미사용)
- 사전 표본 = Date < 시험 컷오프(2024-03-07). 이 중 뒤쪽 50% 를 5개 블록으로 나눠 **확장 윈도우 워크포워드**
  (각 블록 이전 자료로 학습, 두 시장 풀링은 블록 시작일 이전 자료만).
- 점수: 변동성 = 기준선(F0, 같은 모형) 대비 **MSE 개선율** `1 − MSE_cand / MSE_F0`,
  방향성 = 이어붙인 표본외 예측의 **AUC**(시장 평균).
- 타깃별로 F2~F5 × 모형 중 점수 최고 후보를 선택한다. **점수가 F0(및 F1)을 넘지 못하면 선택하지 않는다(개선 없음).**

## 4. 시험 평가와 판정 (사전 확정)
- 선택된 후보와 F0·F1 을 v10 절차(풀링·보정)로 시험 구간에서 평가: R² / AUC, 블록 부트스트랩 95% CI, DM 검정.
- **"개선"의 정의**: 선택된 후보가 F0 와 F1 모두에 대해 (변동성) DM p<0.05 이면서 R² 가 더 높음, (방향성) AUC 가 더 높고
  ΔAUC 부트스트랩 CI 가 0 을 포함하지 않음. 이에 못 미치면 "유의한 개선 없음"으로 보고한다.
- 전체 후보 결과는 탐색적(다중 비교 미보정)으로 함께 표기한다.

## 4-1. 실행 결과 (2026-09-20)
결과 문서: `02_성공실험_변동성방향성예측/개선실험/SUMMARY.md`.

- 선택(시험 미사용): 변동성 = F5(AR+평활 감성) + Ridge, 방향성 = F2(AR+뉴스 강도·주제) + 로지스틱.
- **판정: 개선 아님.** 변동성은 선택 후보가 기준선보다 낮음(미국 R² 0.269 vs 0.323~0.327, 영국 −0.029 vs 0.043~0.056).
  방향성은 AUC 가 높지만(미국 0.544 vs 0.482, 영국 0.553 vs 0.517) ΔAUC CI 가 0 을 포함하고, 뉴스 없는 AR 로지스틱(F0 linear)이 이미 0.544 / 0.538 이라 상승은 뉴스가 아니라 모형 변경(LightGBM→로지스틱)에서 온다.
- 새 강도·주제 피처(F2~F5)는 사전 검증에서 기존 뉴스(F1)를 넘지 못했다.
- 사후 발견한 규칙 결함: 후보를 '같은 모형의 F0·F1' 과만 비교하게 고정해서 전반적으로 나쁜 선형 모형이 선택됨. 사후 조정을 피하기 위해 규칙은 바꾸지 않고 모든 후보의 시험 결과를 공개했다.
- 이후 시험 성적을 보고 후보를 추가·변경하는 시도는 데이터 스누핑이므로 하지 않는다. 독립 검증이 필요하면 2026년 신규 자료로 동결된 모형을 1회 평가해야 한다.
