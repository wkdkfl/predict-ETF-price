# 2014–2025 미국·영국 일별 경제 뉴스 수집 계획 (2026-09-19)

## 1. 목표
- 논문 조사기간 **2014-01-01 ~ 2025-12-31 (4,383일, 주말·공휴일 포함)** 의 **모든 날짜**에
  미국·영국 각각 **최소 1건 이상의 "의미 있는" 경제 뉴스 헤드라인**을 확보한다.
- 저장 위치: `공통데이터/USD/`, `공통데이터/UK/` (각각 별도 파일).
- 배경: 기존 `*_financial_news.csv` 는 고유 뉴스일이 미국 221일 / 영국 713일뿐이라
  (학습 구간 커버리지 3.2% / 12.9%) "뉴스는 예측에 기여하지 않는다"는 결론이 뉴스의 정보력이 아니라
  **데이터 부재**를 반영했을 가능성이 있다.

## 2. 기존 스크립트 진단 — `02_성공실험_변동성방향성예측/_collect_gdelt_news.py` (GDELT DOC API)

재사용하되, 소스를 2014년부터 일별 조회가 가능한 아카이브로 교체한다.

## 3. 소스 후보 실측 (동일 방법: 2014–2025 표본일 직접 요청)

| 소스 | 결과 | 채택 |
|---|---|---|
| **NYT 일별 사이트맵** `nytimes.com/sitemap/YYYY/MM/DD/` | 200, 무키, ~1초/요청. 표본 13일(2014-01-01, 주말, 크리스마스, 2020-03 폭락기, 2025-12-31 등) 전부 `business/` 기사 ≥3건. URL 경로로 섹션 식별 가능 | **미국 채택** |
| **Guardian 일별 비즈니스 아카이브** `theguardian.com/business/YYYY/mon/DD/all` | 200, 무키, ~1.8초/요청. 일 24~30건, 주말·2014·2025-12-31 모두 존재. 헤드라인+standfirst 제공 | **영국 채택** |
| GDELT DOC API | 2017 이전 불가, 429 | 제외 (위 2절) |
| GDELT 원본 GKG/Events 파일 | 접근 가능하나 15분 단위 파일, 연 수백 GB | 제외 (용량) |
| Guardian Content API (`api-key=test`) | 401 | 제외 (키 필요) |
| HuggingFace `financial-news-multisource` | gated (로그인·약관 동의 필요) | 제외 |
| CNBC 사이트맵 / Wayback CDX | 링크 구조 불일치 / 타임아웃·429 | 제외 |

두 사이트 모두 `robots.txt` 가 해당 경로를 허용하고 crawl-delay 지시 없음 (확인 완료).
그래도 저속(요청 간 최소 간격 + 소수 워커)으로 수집한다.

## 4. 설계

### 4.1 파이프라인
1. **수집** — 날짜별로 페이지 1건 조회 → 기사 후보(헤드라인, URL, 섹션, [standfirst]) 파싱
2. **후보 저장** — 전체 후보를 `*_candidates.csv` 에 누적 (재개 가능, 선별 기준을 바꿔도 재크롤링 불필요)
3. **점수화** — 섹션 가중치 + 거시/시장 키워드 가중치 − 비경제(노이즈) 패턴 감점
4. **일별 선택** — 날짜당 점수 상위 최대 10건. 임계 이상이 없으면 **그날 최고점 1건을 fallback 으로 채택**
   (`is_fallback=1`) → "매일 ≥1건" 보장
5. **저장** — 최종본 `*_economic_news_daily.csv`
6. **검증** — 날짜 커버리지, 연도별 분포, 중복/공백/날짜범위 검사 → 리포트

### 4.2 "의미 있는 경제 뉴스" 기준
- **미국(NYT)**: URL 섹션이 `business`, `your-money`, `upshot` 인 기사만 후보. 후보가 0이면 전체 섹션에서 fallback.
  - **날짜 규칙(스모크 테스트에서 발견)**: 일요일 지면 기사는 앞날(토) 사이트맵에 URL 날짜가 하루 뒤로 올라온다
    (2014-03-09 사이트맵의 비즈니스 기사 8건이 전부 `2014/03/10` URL). 사이트맵 날짜 D 를 기사 날짜로 쓰고
    URL 날짜는 D±1일까지 허용한다. 같은 URL 이 인접일에 중복되면 가장 이른 날짜에만 남긴다.
- **영국(Guardian)**: 비즈니스 아카이브 전체가 후보(다른 섹션 교차게재 포함).
  - **휴일 보충(스모크 테스트에서 발견)**: 2018-12-25 처럼 비즈니스 아카이브가 0건인 날이 있다. 그런 날만
    money / politics / uk-news / technology / world 아카이브에서 키워드 점수 상위 기사를 보충하고 `is_fallback=1` 로 표시한다.
    (2018-12-25 → "Tokyo stocks plunge in Christmas rout amid fears over US economy")
    보충해도 경제 기사가 없는 날은 점수 ≤ 1 인 "약한 날짜"로 리포트에 별도 보고한다.
- **키워드 점수**: 시장 영향도가 큰 주제(중앙은행·금리·인플레이션·GDP·고용·침체·관세·증시·실적·환율·유가)는 고가중,
  일반 경제어(은행·주택·소비·인수합병 등)는 저가중.
- **감점**: obituary / review / crossword / podcast / quiz / 스포츠·연예성 패턴.
- **정보 누출 방지**: 기존 파이프라인(`_build_multi_headline_features.py`)의 `CLOSE_PATTERNS`
  ("closed at", "ended the day", "market close" 등 장 마감 요약)와 **동일 정규식**으로 표시(`is_close_summary`)하고
  선택 단계에서 제외 (다른 후보가 전혀 없을 때만 fallback 으로 허용).
- 논문의 `Economic_Lexicon.csv` 는 감성 사전(token/sentiment/polarity)이라 주제 관련도 판별에는 부적합 → 사용하지 않음.

### 4.3 출력 스키마 (기존 `*_financial_news.csv` 와 호환: year, month, date, headline, source 유지)
`year, month, date, headline, source, section, url, relevance_score, day_rank, is_fallback`

| 파일 | 위치 |
|---|---|
| 미국 최종본 | `공통데이터/USD/US_economic_news_daily.csv` |
| 미국 후보 전체 | `공통데이터/USD/US_economic_news_candidates.csv` |
| 영국 최종본 | `공통데이터/UK/UK_economic_news_daily.csv` |
| 영국 후보 전체 | `공통데이터/UK/UK_economic_news_candidates.csv` |

| 검증 리포트 | `공통데이터/economic_news_collection_report.md` |

### 4.4 운영
- 저속·재개 가능: 워커 3개 + 소스별 최소 요청 간격, 429/5xx/타임아웃은 지수 백오프.
  완료 날짜는 `공통데이터/_news_cache/` 에 기록 → 중단 후 재실행 시 이어서 수집.
- 연속 차단(403/429 지속) 감지 시 즉시 중단하고 재개 안내 출력.
- `--smoke-test` (표본 6일만 조회, 파일 미생성), `--market US|UK`, `--start/--end`, `--select-only`(재선별), `--verify`.

## 6. 한계 (논문에 쓸 때 주의)
- 각 국가 **단일 매체**(NYT / Guardian)이므로 "미국 전체 / 영국 전체 뉴스"가 아니라 대표 매체의 경제 섹션이다.
- 날짜는 **매체 발행일**(NYT 미 동부, Guardian 영국 시각). 기사 시각은 없어 장중/장후 구분 불가 →
  예측 시점 정렬(당일 vs 전일 뉴스)은 모델링 단계에서 결정.
- Guardian 은 영국 매체이지만 비즈니스 섹션에 글로벌 기사가 섞임(영국 시장 영향 포함이라 유지).
- 키워드 점수는 휴리스틱이다. 후보 전체를 남겨두므로 기준 변경 시 재선별 가능.
