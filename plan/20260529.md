**방어**: RF가 US R²=0.830, UK R²=0.932로 최고. Stacking은 KFold 시간순서 교란 + Ridge 메타러너 한계로 US 0.575.

### Q2. News_Only에 자기회귀 피처가 포함된 것 아닌가?
**방어**: 맞음. News_Only에 absret_lag, rolling_absret 포함. 순수 텍스트 기여 분리는 향후 과제. 핵심은 Financial_Only 대비 News_Only가 압도적 우위.

### Q3. 뉴스 발행 시각으로 마감 전/후 분리했는가?
**방어**: API가 일자만 제공, 시간 분리 불가. 사후 뉴스 정규표현식 필터 적용. "비대칭 시차" 설정으로 명시. 완벽한 분리는 실시간 피드 필요.

### Q4. 수익률 예측 불가인데 방향은 AUC 0.84?
**방어**: Christoffersen & Diebold (2006)에 의해 이론적으로 양립 가능. 변동성 비대칭(leverage effect)에서 방향 예측력 발생. AUC가 초과수익 보장 아님.

### Q5. 2025년 12월 데이터?
**방어**: v18에서 수정 완료. 분석 기간 2014.1~2024.12.

### Q6. HAR/GARCH baseline보다 우수한가?
**방어**: Ridge(HAR-style 선형)가 R²=-1.62로 열등. RF에 GARCH-style 입력 이미 포함. 정식 GARCH 비교는 미포함 (한계로 명시).

### Q7. 거래비용 반영 후 경제적 가치?
**방어**: 통계적 성능 평가에 초점. 거래비용 반영 백테스트는 향후 연구.

### Q8. Stacking KFold는 미래정보 누출?
**방어**: 인정. KFold(shuffle=False) 사용으로 시계열 순서 교란 가능. Stacking이 RF보다 낮은 원인 중 하나. PurgedKFold는 향후 과제.

### Q9. UK R²=0.932가 너무 높다?
**방어**: (1) Guardian 뉴스 풍부 (36,739건), (2) FTSE 100 변동성 규칙적, (3) Walk-Forward 5-fold 평균 0.930으로 일관, (4) target ETF의 OHLCV는 독립변수 미포함.

### Q10. Data snooping?
**방어**: (1) 전 모델 결과 전수 보고, (2) Walk-Forward 5-fold, (3) DM test + Bootstrap CI, (4) 하이퍼파라미터는 validation에서만 결정.

## 9. 코드 아키텍처 메모

### `_run_enhanced_models_v3.py` 핵심 파라미터
- `OPTUNA_TRIALS_FULL = 100` (메인 실험)
- `OPTUNA_TRIALS_ABL = 30` (ablation, v3에는 ablation 코드 없음)
- `TRAIN_FRAC = 0.70`, `VAL_FRAC = 0.15` (test = 마지막 15%)
- **변동성 타겟**: `log(|r_{t+1}| + 1e-8)` (log-vol)
- **방향성 타겟**: `sign(r_{t+1})` → 이진 분류 (AUC)
- **피처 세트**: FinBERT 감성 + 금융지표 + leverage effect + RSI + VIX dynamics + DoW + vol_ratio + absret_surprise
- **t-1 lagging**: 모든 외생 피처 1영업일 지연 적용 (look-ahead bias 방지)
