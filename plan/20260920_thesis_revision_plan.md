## 2. 재실험 설계

### 원칙
1. **뉴스만 교체**: 시장 데이터·거래일 필터·타깃·피처 정의·모델 하이퍼파라미터·부트스트랩·DM 검정은 v10 프로토콜과 동일. yfinance 재다운로드 없음(값 변동 혼입 방지).
2. **뉴스 선별 기준 동결**: `collect_economic_news.py`의 점수·임계값(THRESH=3, MAX_PER_DAY=10)을 지금 상태로 고정. 모델 성능을 본 뒤 재선별하지 않는다. 변경이 불가피하면 논문에 명시.
3. **동일 환경 비교**: 기존 뉴스 조건과 신규 뉴스 조건을 **같은 환경에서 함께 실행**한다.
4. **결정성 검증**: `PYTHONHASHSEED`를 바꿔 2회 실행해 결과가 완전히 동일함을 확인(README 자료문제 3).

### 신규 뉴스의 정렬 규칙 (기본안)
- 행 = 거래일 t. 뉴스 피처는 기존과 같이 t 행에 **그대로**(shift 없음), 금융 피처만 t−1 — 타깃이 t+1 이후이므로 t일 발행 뉴스는 예측 시점에 이미 알려진 정보.
- 비거래일(주말·공휴일) 뉴스는 **다음 거래일 행에 합산**(직전 거래일 종가 이후 누적 뉴스). 그대로 두면 토·일 뉴스가 거래일 필터에서 버려짐.
- 전방 보간 없음. `news_available`은 실제 뉴스 유무(신규 데이터에서는 거의 항상 1).
- 감성 피처 16종·임베딩 PCA 정의는 기존과 동일(`_build_multi_headline_features.py`의 집계 방식). `is_fallback` 날짜도 유지하되 결과를 fallback 제외로 재계산하는 **강건성 검정**을 추가.
- 장 마감 요약 패턴(`CLOSE_PATTERNS`) 제외는 기존 파이프라인과 동일하게 적용.

### 계획 대비 변경·발견
1. **PCA 솔버를 `full` 로 고정**(주 결과). 기존 환경(sklearn 1.0.2)을 재현할 수 없고 auto 는 버전 의존적이라, 결정적인 full 을 주 결과로, auto 는 구현 민감도 측정용으로 병기.
2. **시험 구간 재산정 결과 컷오프가 기존과 동일**(표본이 같음). 학습 <2022-05-19, 검증 <2024-03-07, 시험 452일 / 434일 → 기존·신규를 같은 시험 표본에서 직접 비교 가능.
3. **`Financial_Only` 그룹에 뉴스 파생 열 2개(`sent_x_vix`, `sent_x_vol`) 혼입** 발견(v10 부터 존재). 기존 그룹 값은 유지하고 `Financial_Clean` 을 추가 행으로 계산.
4. 진단 조건 (c)(신규 뉴스를 기존 커버리지로 솎아낸 조건)는 수행하지 않음 — 결과가 소스·척도 차이로 이미 해석이 제한되므로 논문 작성 단계에서 필요 여부를 다시 판단.

### 결과 요약 (상세는 SUMMARY.md)
- 뉴스 증분(AR_Only→AR+News) 변동성 DM: 4개 조건 모두 비유의(p 0.47~0.90). 신규 뉴스로 바꿔도 결론이 바뀌지 않음.
- 기존 대비 신규 뉴스의 R² 차이는 −0.034 ~ +0.043로 부호가 일관되지 않고, PCA 솔버 잡음(최대 약 0.05)과 같은 범위.
- 방향성: 미국 Full AUC 0.591 → 0.573(신규 CI 하한 0.497). **신규 뉴스가 예측을 분명히 개선했다는 증거는 얻지 못했다.**
- 논문 서술 방향은 논문 작성 시점에 결정(인터뷰 Q4).

## 5. 위험과 한계 (논문에 반영할 것)
- **소스 교란**: 신규 뉴스는 다른 매체·다른 성격이므로 개선(또는 무개선)의 원인이 커버리지인지 소스인지 단정할 수 없음 → 진단 조건 (c)로 부분 분리.
- **단일 매체**: 국가별 대표 매체 1개(NYT / Guardian)의 경제 섹션. 미국 주말 34%·영국 주말 10%가 fallback(일 단위 정보량 낮음).
- **시험 구간 재사용**: 동일 시험 구간(2024-03-07~)이 v3~v13 개발 내내 쓰였으므로 신규 결과도 독립 검증은 아님.
- **다중 비교**: 피처군·시장·시계별 다수 검정 → 사전 지정한 비교(가설 H1~H4)만 주 결과로, 나머지는 탐색적으로 표기.
- **정보 시점**: 매체 발행일만 있고 기사 시각 없음. Guardian "– as it happened" 라이브블로그는 당일 결과 포함 가능. 타깃이 t+1 이후이므로 t일 뉴스 사용은 타당하나 t일 장중 결과가 뉴스에 반영돼 있을 수 있음.
- **재현성**: Python 3.7 → 3.12 환경 차이. Phase A 결과에 따라 비뉴스 수치도 변동 가능.
