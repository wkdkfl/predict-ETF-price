# 방향성 v18 사전 고정 프로토콜 (2026-10-28, 실행 전 작성)

목적: v15~v17 에서 시도하지 않은 세 가지 방안으로 5일 방향성 예측을 개선할 수 있는지 검증한다.
**결과를 본 뒤 아래 설정을 바꾸지 않는다.** 기준에 못 미쳐도 그대로 보고한다.

## 0. 누적 탐색에 대한 고지 (결과와 무관하게 먼저 적는다)
- 방향성은 v3~v17 에 걸쳐 반복 탐색되었다. v16·v17 이 같은 외부 평가 구간(2018-03~2025-12)을 이미 사용했으므로
  v18 의 외부 OOS 도 **독립 검증이 아니다.** v18 결과는 "앞선 탐색을 거친 뒤 추가로 시도한 방안"으로만 해석한다.
- 미사용 신규 표본(2026년)은 이 PC 에 자료가 없어 쓰지 못한다(yfinance 미설치, 원 환경 변경 금지).

## 1. 세 가지 방안
1. **fold 별 확률 표준화 (CAL)** — v17 영국은 8개 fold 모두 AUC>0.5(평균 0.58)인데 통합 AUC 는 0.527 이었다.
   fold 마다 재학습된 모형의 확률 수준이 달라 통합 순위가 섞이는 것으로 진단했다.
   선택된 모형의 평가 예측 logit(p) 를 **같은 모형의 해당 시장 학습 행 예측 logit 의 평균·표준편차로 z 표준화**한다.
   시험 라벨은 쓰지 않는다. 상위 3 앙상블은 표준화한 z 를 평균한다.
   (fold 내부 순위는 단일 모형에서 바뀌지 않으므로, 이 방안은 시점 간 확률 비교 가능성을 개선하는 것이다.)
2. **확장 금융 피처 (FIN_ext, 7열)** — 단기 주가 방향 문헌의 변수. 모두 t-1 시차(논문 금융지표 규칙과 동일).
   - `vix_term` = log(VIX9D / VIX)            (VIX 기간구조)
   - `vvix_dev` = log(VVIX) − 20일 평균        (변동성의 변동성)
   - `credit_5d` = log(HYG/LQD) 5일 변화       (신용 스프레드 대리)
   - `slope` = US30Y − US5Y, `slope_5d` = 그 5일 변화 (장단기 금리차)
   - `tlt_5d`, `uup_5d` = 로그 5일 수익률       (장기채, 달러)
   - 자료가 2024-12-30 에서 끝나므로 **fold 8(2025) 에서는 FIN_ext 를 포함한 후보를 후보군에서 제외**한다.
     앞쪽 결측은 직전 값으로만 채운다(미래 값 사용 금지).
3. **dir20 전체 기간 평가** — v15 에서 dir20 은 단일 분할(유효 표본 ≈23)로만 평가되었다. 같은 중첩 WF 로 전체 기간 평가한다.
   엠바고 = 블록 길이 = 40행(2h).

## 2. 설계 (v17 과 동일한 부분)
- 표본 `_regime_fixes_v7.prep()` (기존 뉴스, PCA_SOLVER=full), 외부 8-fold 확장 WF(미국 날짜 35% 분위 이후), pooled 학습.
- 내부 선택: 외부 학습 구간 뒤쪽 50% 를 3 구간으로 나눈 확장 WF, 시장별 내부 AUC 평균으로 순위.
- 분류기 7종: v17 과 동일 (logit C 0.001/0.01/0.1, LGBM shallow/mid/v10, RF d4).
- 피처군 6종: v17 의 AR / FIN_clean / AR+FIN_clean / Full + **AR+FIN_ext / AR+FIN_clean+FIN_ext** → 후보 42개.
- 선택 규칙: 단일 최고(best), 상위 3 평균(top3). 각각 원 확률(raw)과 표준화(cal) 두 가지로 보고.

## 3. 판정
- **확증 family (dir5)**: 2 규칙 × 2 보정 × 2 시장 = 8 개 단측 부트스트랩 p(AUC ≤ 0.5)에 Holm 보정.
  블록 10, 5,000회. 점추정 0.6 이상 여부와 CI 하한도 함께 보고한다.
- **개선 판정**: 같은 시장에서 v17 top3 대비 쌍체 ΔAUC 의 95% CI 가 0 을 배제할 때만 "개선"으로 인정.
- **보조 family (dir20)**: 같은 8 개 비교에 별도 Holm. 블록 40. 다수 클래스 기준(상승 비율)을 반드시 병기.
  dir20 은 표적이 다르므로 RQ2(5일)의 답을 대체하지 않는다.
- 각 fold 선택 후보, 내부·외부 AUC 를 모두 공개한다.

## 4. 알려진 한계
- 위 0 절 (비독립 평가 구간).
- FIN_ext 는 fold 8 에서 사용 불가 → 확장 피처의 효과는 fold 1~7 에서만 측정된다.
- `prep()` 의 임베딩 PCA 는 고정 컷오프(2022-05-19)에서 적합되어 Full 피처군 초기 fold 에 경미한 누출이 있다(v16 과 동일).
