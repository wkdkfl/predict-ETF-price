# 방향성 v16 사전 고정 프로토콜 (2026-10-07, 실행 전 작성)

목적: 논문 RQ2(5일 누적 방향성)에 대해 (2) 변동성 예측값을 방향성 피처로 쓰는 방안과
(3) 단일 시험 구간 대신 전체 기간 확장 워크포워드로 평가하는 방안을 검증한다.
(1) 정칙화 로지스틱은 v15 에서 이미 검증했으므로 기준선으로만 포함한다.

**결과를 본 뒤 아래 설정을 바꾸지 않는다.** 결과가 기준에 못 미쳐도 그대로 보고한다.

## 평가 설계
- 표본: `_regime_fixes_v7.prep()` (기존 뉴스, 논문 §4.5 와 동일), 표적 `dir5`.
- 외부 워크포워드: 미국 날짜의 35% 분위 이후를 8개 연속 구간으로 나눈 공통 날짜 컷오프. 두 시장에 같은 컷오프 적용.
- 학습: 각 fold 시작일 이전 두 시장 자료를 합쳐 학습(pooled). 시장별 마지막 10행은 엠바고로 제외(5일 라벨 겹침 방지).
- 표준화: fold 학습 자료로만 적합.

## 모형 (4개, 고정)
| ID | 피처 | 분류기 |
|---|---|---|
| A_v10 | Full 71 | LightGBM v10 설정(600그루, depth 5, lr 0.04, ...) |
| B_v15 | AR_Only 25 | L2 로지스틱 C=0.01 |
| C_vol | AR_Only 25 + VOL 5 | L2 로지스틱 C=0.01 |
| D_ens | AR_Only 25 + VOL 5 | C_vol 확률과 얕은 LightGBM(depth 2, 300그루, lr 0.02, min_child_samples 200, subsample 0.8, colsample 0.8, reg_lambda 10) 확률의 평균 |

VOL 5열:
1. `vhat` — 5일 로그 실현변동성 예측값. AR_Only LightGBM(v10 설정, 차분 표적)으로 산출.
   학습 행의 값은 fold 학습 구간 안 5분할 확장 OOF 예측(첫 분할은 값이 없어 C/D 학습에서 제외).
   평가 행의 값은 fold 학습 전체(엠바고 적용)로 적합한 모형의 예측.
2. `vhat_chg` = vhat − rv5_past
3. `vrp` = log(vix/100/√252) − rv5_past (내재 대 실현 변동성 격차)
4. `vix_chg_5d`, 5. `vix_ma5_ratio`

## 주 가설과 판정
- **주 가설: C_vol 의 미국 OOS AUC 의 95% 블록 부트스트랩 CI 하한 > 0.5.** (블록 10, 5,000회)
- 보조: 영국 C_vol, D_ens, A·B 대비 쌍체 ΔAUC CI.
- 다중 비교: 4모형 × 2시장 = 8개 "AUC>0.5" 단측 부트스트랩 p 에 Holm 보정을 적용해 함께 보고.
- 참고용: 논문 시험 구간(≥2024-03-07)만 잘라낸 AUC. 이 구간은 v3~v15 개발 중 반복 사용되었으므로 판정에 쓰지 않는다.
