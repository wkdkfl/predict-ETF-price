## 3. 단계별 실행 계획

### Phase 1 — 사실 검증 (요구사항 6·7·10) 【최우선】
- 초록(국문 para 40~43, 영문 60~62, 논문요약 51~54) + 본문 전체의 **모든 정량 수치 목록화** 후 실제 CSV와 1:1 대조표 작성.
- 대조 대상: Walk-Forward 평균 R²(US 0.844 / UK 0.930), DM p<0.01, Bootstrap 95% CI, News_Only 재현율(~90% 변동성 / ~100% 방향성), ΔR²≈0.62~0.66, 헤드라인 건수(US 22,971 / UK 36,739), 데이터 기간(2014~2024), Ablation 수치.
- **불일치·근거 없는 수치 발견 시 수정안을 표로 제시 → 승인 후 반영**. 근거 없는 단정·과장 표현("최초의", "완벽히" 등) 별도 플래그.

### Phase 2 — 참고문헌·인용 검증 (요구사항 2·3·4)
- 비교논문 [47]~[51] **인용수·발행연도 웹 재검증**:
  - Bajgai&Zhou(2026): 미래연도 → 50+ 불가 → **대체 후보 탐색**(방향성·뉴스감성, 최근 10년, 고인용).
  - Wang(2023, IEEE BigData): 인용수 확인, 50 미만 시 대체.
  - Rekabsaz(2017)/Ding(2015)/Xu&Cohen(2018): 인용수 확인(통과 예상).
- 권위 논문 보강: 필요 시 변동성·텍스트금융 분야 고인용 논문 추가.
- 박사학위 논문: 주제 부합 dissertation 1~2편 탐색 → 있으면 추가, 없으면 "권위 논문으로 충족" 명시.
- 본문 인용번호 ↔ 참고문헌 목록 **전수 정합성 점검**(누락·중복·순서).

### Phase 3 — 초록 완성 (요구사항 1·4·5·6·7·8)
- 4단락 구조(선행연구→문제제기→연구주제→연구의의+차별점) 유지 확인, 차별점 마지막 배치 확인.
- Phase 1·2 결과로 수치·인용번호 갱신.
- 국문 초록·영문 Abstract·논문요약 **3자 수치·표현 일치** 교정.

### Phase 4 — 주제 명료성 점검 (요구사항 9)
- 논문이 다루는 5갈래(변동성 / 방향성 / 수익률예측 실패 / 미래편향 / 교차시장) 위계 분석.
- 핵심 주제와 보조 발견이 명확히 구분·정렬됐는지 판단 → 혼재·산만 지점 식별 후 재구성 제안(승인 후 반영).

### Phase 5 — 그림·표 정리 (요구사항 11)
- 표 목차 순서·번호 수정(표2/3 뒤바뀜, 목차 누락 표17~23·26 확인).
- 그림 번호 스타일 통일(`<그림 N>` 형식, 현재 그림9~14 불일치).
- **방법론 개념도**(파이프라인·스태킹·Walk-Forward·아키텍처): AI 생성 지양 → 표준 문헌 도식을 **출처 명기하여 인용·재현**, 정 못 찾으면 깔끔한 자체 제작.
  - ※ 문헌 그림 직접 전재는 저작권 이슈가 있어, 개념을 **일관 스타일로 재작도 + 원출처 인용**을 기본안으로 제안.
- **결과 그림**(성능 막대·중요도·산점도 등)은 자체 데이터이므로 유지하되 가독성 점검.
- 각 그림·표가 본문에서 참조·설명되는지 확인, 불필요한 것 제거.

### Phase 6 — 문체 개선 (요구사항 12)
- AI 티나는 패턴(기계적 병렬·"종합하면"·과도한 열거·번역투) 완화, 자연스러운 학술 국문체로 교정. **의미·수치 불변**.

### Phase 7 — 2·3장 재구성: 핵심 내용 집중 (요구사항 9·10·4 연계) 【신규】
**목표**: 권위 논문의 흐름·분량 기준에 맞춰, 불필요한 설명을 걷어내고 핵심·신규 기여에 지면을 재배분. 근거 없는(인용 없는) 서술 제거.

**현황 진단 (v26 기준)**
- 2장(선행연구): 5,904자 / 5개 절 — 분량은 적정하나 **인용번호 누락·내용 중복** 문제.
- 3장(데이터·전처리): 11,525자 / 8개 절 — **2장의 약 2배**. 중복 서술·교과서식 유도·반복 헤지로 인한 과잉.
